# Inhale recording

- **Title:** Cigarette inhale.wav
- **Creator:** kczub
- **Original page:** https://freesound.org/people/kczub/sounds/268963/
- **License:** CC0 1.0, https://creativecommons.org/publicdomain/zero/1.0/
- **Downloaded asset:** Freesound high-quality MP3 preview, https://cdn.freesound.org/previews/268/268963_5099183-hq.mp3
- **Retrieved:** 2026-09-27

The original is a 2.140-second, 44.1 kHz mono WAV. This project uses the publicly available HQ MP3 version, embedded into the standalone HTML. In playback the recording is segmented with overlapping fades for variable-length draws. Exhalation, rain, lighter and contact sounds are synthesized locally.
